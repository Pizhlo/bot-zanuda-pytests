# Проверка вывода pytest

Эта ветка оставлена для ручной проверки пользователем. Не сливать её в основную ветку:
workflow намеренно ломает подготовку БД в задании setup и добавляет падающий тест в pytest.
Оба задания должны быть красными; последний шаг должен быть зелёным. Он проверяет
настоящую сводку, исходный failure и отсутствие контейнеров, сетей и томов.

Ручной запуск: Actions → workflow auth-service.yaml → Run workflow → эта ветка.
В auth_image указать `pizhlo/bot-zanuda-auth-service:auth-env-20261010-008efff`.
В Summary ожидаются «pytest не запускался» и «1 failed, 86 passed» соответственно.
Обычные успешные прогоны находятся в BZ-65 и BZ-185. Тестовые образы latest не обновлялись.
Ветку удаляет пользователь после проверки результата.
