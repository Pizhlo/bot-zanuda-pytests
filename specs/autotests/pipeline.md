# Пайплайн тестов auth-service

Окружением управляет testkit, подключённый сабмодулем на конкретном коммите.
Поддерживается только Linux. `make integration-run` готовит инфраструктуру, ждёт
готовности auth-service после его собственных миграций схемы, загружает данные,
выполняет `make test-auth-service` и завершает прогон.
`integration-up` заканчивается до загрузки данных и pytest, оставляя окружение для IDE.

## Контракт тестовых данных

`make test-data-auth-service-up` напрямую вызывает `tools/seed_auth.py`, без Docker
внутри команды. Используется golang-migrate **v4.19.1**, включённый в образ pytests.
Та же версия требуется при прямой загрузке на хосте; путь к бинарнику задаётся через
`MIGRATE_BIN`. Источник по умолчанию — `testdata/auth-service` относительно репозитория
скрипта, независимо от текущей рабочей папки. `TESTDATA_PATH` переопределяет источник.

Подключение берётся из раздела `postgres` файла `PYTEST_CONFIG` (по умолчанию config.yaml)
либо из явного `TESTDATA_DATABASE_URL`. Обёртка принудительно задаёт отдельную таблицу
истории `testdata_schema_migrations`; история приложения `schema_migrations` не меняется.
Применяются только новые версии. Повторный up без изменений успешен, но не восстанавливает
данные, изменённые тестами. Отсутствующий или пустой источник, ошибка SQL и dirty
останавливают загрузку. Автоматические force, drop, down и повторы не выполняются.

## Версии и результат

Локальный запуск и CI этого репозитория собирают тесты и SQL из текущих исходников.
Образ auth-service по умолчанию latest; AUTH_IMAGE переопределяет его.
CI сервиса использует свою сборку приложения с опубликованным тегом тестов
(по умолчанию latest).

Полный локальный успех удаляет контейнеры и тома прогона и выводит результат pytest
без файлов отчётов. Ошибка сохраняет окружение и `.logs/<run-id>/run.log`.
В CI вывод подготовки, pytest и Docker попадает в журнал GitHub Actions;
попытка уборки выполняется при любом исходе. Сервер отчётов и загрузка артефактов не нужны.
При отдельных командах и запуске pytest из IDE окружение удаляет разработчик.
